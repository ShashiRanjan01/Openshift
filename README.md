# 🚀 OpenShift Troubleshooting Simulator

An interactive, browser-based learning lab designed to help developers, DevOps engineers, and beginners understand and troubleshoot common issues in **Red Hat OpenShift and Kubernetes environments**.

🔴 **Live Demo:** [Launch OpenShift Ops Lab](https://shashiranjan01.github.io/Openshift/)

📦 **GitHub Repository:** [ShashiRanjan01/Openshift](https://github.com/ShashiRanjan01/Openshift)

---

## 📌 Overview

Troubleshooting applications running on OpenShift can be challenging, especially when dealing with unhealthy pods, service connectivity issues, application errors, or HTTP 503 responses.

The OpenShift Troubleshooting Simulator provides an interactive environment where you can explore application health, investigate common failures, practice troubleshooting commands, and learn how to identify potential root causes.

It is designed for hands-on learning without requiring access to a real OpenShift cluster.

## ✨ Features

* **Interactive troubleshooting dashboard** — Explore simulated application health and troubleshooting scenarios.
* **Application architecture visualization** — Understand the flow from Route → Service → Pod → Application.
* **Multiple troubleshooting scenarios** — Practice diagnosing common OpenShift application issues.
* **Guided and challenge modes** — Learn step by step or test your troubleshooting skills independently.
* **Simulated terminal** — Practice OpenShift CLI (`oc`) commands in a safe, simulated environment.
* **Hints and suggested fixes** — Get guidance to understand the likely root cause and possible resolution.
* **Verification steps** — Learn how to verify application health after applying a simulated fix.
* **Progress tracking and scoring** — Track your learning progress as you work through scenarios.
* **Knowledge checks** — Test your understanding with quizzes and explanations.
* **Responsive design** — Use the simulator on desktop, tablet, or mobile devices.

## 🧪 What You Can Learn

The simulator helps you build troubleshooting skills around topics such as:

| Topic               | Learning objective                                        |
| ------------------- | --------------------------------------------------------- |
| Routes              | Understand application exposure and route-related issues  |
| Services            | Learn how services connect traffic to application pods    |
| Pods                | Investigate pod health and simulated workload failures    |
| Application health  | Identify symptoms of unhealthy applications               |
| HTTP 503 errors     | Understand common causes of service-unavailable responses |
| CLI troubleshooting | Practice simulated `oc` commands                          |
| Root cause analysis | Follow symptoms, investigate causes, and verify fixes     |

*The exact scenarios and commands available depend on the simulator version.*

## 🖥️ How to Use

1. Open the [Live Simulator](https://shashiranjan01.github.io/Openshift/).
2. Explore the dashboard and available troubleshooting scenarios.
3. Select a scenario to investigate.
4. Review the symptoms and application architecture.
5. Use the available hints and simulated terminal commands.
6. Identify the likely root cause and apply the suggested simulated fix.
7. Verify the result and review your progress or score.

## 🚀 Run Locally

You can run the project locally without installing any dependencies.

1. Clone the repository:

   ```bash
   git clone https://github.com/ShashiRanjan01/Openshift.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Openshift
   ```

3. Open `index.html` in your browser.

Alternatively, use a local development server if you prefer.

Always validate commands and troubleshooting steps in an appropriate environment before using them in production.
